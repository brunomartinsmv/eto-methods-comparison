# Code of Conduct

## Our commitment

This project aims to support open, reproducible scientific work. Contributors, users, and maintainers are expected to participate respectfully and constructively, regardless of career stage, institution, nationality, language, identity, or technical background.

## Expected behavior

- Be respectful and professional in issues, pull requests, reviews, and discussions.
- Critique methods, evidence, and code without personal attacks.
- Be clear about uncertainty, limitations, and provenance.
- Give appropriate credit for data, methods, software, and scientific ideas.
- Help keep the repository usable for external readers who want to install, run, interpret, and cite the work.

## Unacceptable behavior

- Harassment, insults, discriminatory language, or intimidation.
- Publishing private information without explicit permission.
- Misrepresenting scientific results, authorship, data provenance, or citations.
- Introducing malicious code, credentials, or intentionally misleading documentation.
- Repeatedly ignoring maintainer requests about scope, reproducibility, or respectful communication.

## Enforcement

Maintainers may edit or remove comments, close issues, reject contributions, or block participants when behavior harms the project or its community. Enforcement decisions should be proportionate, documented when appropriate, and focused on protecting constructive scientific collaboration.

## Reporting

Report conduct concerns privately to the maintainer when possible, or through GitHub if no private channel is available. Include enough context to understand what happened. Reports will be handled with care and with respect for the privacy of the people involved.

## Attribution

This code of conduct is adapted for a small academic software project and is inspired by common open-source community standards, including the Contributor Covenant.
