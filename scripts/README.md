**EN**
Python pipeline for reproducibility. The recommended single entry point is `quickstart`. Individual steps also exist: `clean`, `compute-eto`, `limited-data`, `calibrate`, `aggregate`, `metrics`, `plots`, `pca`, `validate-data`, `analyze-uncertainty`, `summarize`, `export-supplement`, and `all`. Taylor diagrams (daily and monthly) are generated by `plots`.

## Uso / Usage
```bash
python -m scripts.cli quickstart --year 2024
python -m scripts.cli quickstart --year 2024 --site manaus
python -m scripts.cli clean --input data/raw/Evapo.xlsx --output data/cleaned
python -m scripts.cli compute-eto --year 2024
python -m scripts.cli compute-eto --year 2024 --site manaus
python -m scripts.cli limited-data
python -m scripts.cli calibrate --site manaus --method hargreaves_samani
python -m scripts.cli calibrate --site manaus --method hargreaves_samani --train-start 2024-01-01 --train-end 2024-06-30 --test-start 2024-07-01 --test-end 2024-12-31
python -m scripts.cli aggregate --input data/cleaned --output outputs/results
python -m scripts.cli metrics --input data/cleaned --output outputs/tables
python -m scripts.cli plots --input data/cleaned --output outputs/figures
python -m scripts.cli pca --site manaus
python -m scripts.cli pca --all-sites
python -m scripts.cli validate-data --year 2024
python -m scripts.cli analyze-uncertainty --year 2024
python -m scripts.cli summarize
python -m scripts.cli all --year 2024
python -m scripts.cli all --year 2024 --site manaus
python -m scripts.cli all --year 2024 --site piracicaba
python -m scripts.cli all --year 2024 --all-sites
python -m scripts.cli all --year 2024 --use-precomputed-eto
python -m scripts.cli export-supplement
```

Sites are configured in `configs/sites.yml`. Method column mappings and short labels are configured in `configs/methods.yml`.
Petrolina uses `reader.format: inmet_limited` and `full_penman_monteith: false`. Read it with `validate-data --site petrolina` or `clean --site petrolina`. Those commands label the station-status flag and do not estimate radiation. Comparison commands reject that site. A fair semiarid Penman-Monteith comparison still needs a radiation-bearing series.
`--use-precomputed-eto` is the current default for cleaning raw spreadsheets and preserves the legacy-compatible pipeline. The `compute-eto` command calculates ET0 from standardized cleaned meteorological variables and writes `outputs/results/{site}_daily_eto.csv`; `metrics` prefers that computed file when available.

## Comandos cientificos / Scientific commands
- `validate-data`: gera relatorios auditaveis de qualidade em `outputs/reports/`, incluindo a contagem de dias fora da envoltoria de radiacao FAO-56/ASCE e `{site}_radiation_screen.csv`.
- `metrics`: mantem as tabelas do ano completo e acrescenta `{site}_daily_metrics_radiation_screen.csv` nos dias dentro da envoltoria. `rad_net_mj_m2_d` nao e recalculada.
- `compute-eto`: calcula ET0 diaria a partir de variaveis meteorologicas limpas e escreve `outputs/results/{site}_daily_eto.csv`.
- `pca`: roda uma analise PCA opcional e exporta loadings, variancia explicada e biplot em `outputs/tables/` e `outputs/figures/`.
- `analyze-uncertainty`: gera intervalos bootstrap, erros sazonais e analise de viés por faixa de ETo. O padrão reamostra dias de forma independente (`resampling=iid`, `block_length=1`). `--bootstrap moving-block` usa blocos móveis e grava o comprimento do bloco na mesma tabela.
- `limited-data`: recompute Penman-Monteith com substitutos FAO-56 para vento, umidade, radiacao ou os tres, e pontua essas series, mais Hargreaves-Samani e Turc, contra a Penman-Monteith de dados completos nos mesmos dias. Escreve `outputs/tables/{site}_limited_data_metrics.csv`. Com o input padrao, a referencia vem de `outputs/results/{site}_daily_eto.csv` quando o arquivo existe.
- `calibrate`: ajusta coeficientes locais opcionais para `hargreaves_samani`, `turc` e `radiation_temperature`, sempre com separacao temporal treino/teste. Com o input padrao, usa a referencia Penman-Monteith calculada em `outputs/results/{site}_daily_eto.csv` quando ela existe; para inputs customizados, use `--results-input` para apontar o diretorio de resultados calculados correspondente. Quando `--results-input` e informado, `{site}_daily_eto.csv` deve existir nesse diretorio. Escreve `outputs/tables/{site}_{method}_calibration_coefficients.csv` e `outputs/tables/{site}_{method}_calibration_metrics.csv`.
- `summarize`: resume os melhores metodos por localidade e escala temporal a partir de `outputs/tables/`.
- `quickstart`: executa o pipeline completo, gera relatorios HTML, exporta o supplement e escreve `outputs/index.html`.
- `export-supplement`: copia CSVs atuais de tabelas, resultados intermediarios e relatorios para `outputs/supplement/`, excluindo `legacy/`.

## Modulos / Modules
- `config.py`: caminhos, parametros e carregamento de `configs/*.yml`
- `eto_layers.py`: classificacao preparatoria de dados meteorologicos, variaveis derivadas e colunas de ETo
- `compute_eto.py`: integracao das funcoes puras de ET0 com DataFrames meteorologicos padronizados
- `limited_data.py`: cenarios de Penman-Monteith com substitutos FAO-56 para vento, umidade e radiacao
- `calibration.py`: ajuste local opcional de coeficientes com validacao temporal separada
- `eto_methods.py`, `fao56.py`, `conversions.py`: funcoes puras para calculo de ET0 e conversoes de unidades
- `io.py`: leitura e padronizacao
- `cleaning.py`: tratamento de falhas
- `aggregate.py`: agregacoes
- `metrics.py`: metricas estatisticas
- `radiation_screen.py`: envoltoria FAO-56/ASCE de radiacao global e contagem de dias fora dela
- `plots.py`: figuras
- `pca_analysis.py`: analise PCA opcional
- `summary.py`: sintese dos principais resultados
- `cli.py`: interface de linha de comando
